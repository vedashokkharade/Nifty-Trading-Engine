NIFTY 50 Gamma Exposure & Options Analytics Engine
A Python-based Streamlit dashboard for analysing dealer positioning and options market dynamics in NIFTY 50.

Features:
Dealer Gamma Exposure (GEX)
Dealer Delta Exposure (DEX)
Call Wall & Put Wall Detection
Put-Call Ratio (PCR)
ATM Implied Volatility Analysis
Expected Move Calculation
Live Data Refresh
NSE Option Chain CSV Upload

Technology Stack:
Python
Streamlit
Pandas
NumPy
Plotly

Purpose
This project was developed to better understand market microstructure, dealer hedging flows, volatility dynamics, and options positioning in the Indian equity derivatives market.
